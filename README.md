# 高性价比人生指南 · 34 个主题浏览站

《高性价比人生指南》完整版（884 页、34 个生活主题、767 条建议）

**三级浏览结构**

1. **一级** — 首页 34 个主题卡片，每张卡带节选说明与条目数
2. **二级** — 点开主题，看该主题下的全部条目（编号、标题、首句摘要、证据等级）
3. **三级** — 点开条目，看完整解释：结论、成本、收益、备注、来源（含可点击链接）

**筛选与检索**

- 顶部全局搜索：跨 34 个主题搜索全部条目，标题与摘要命中处高亮，结果可分享（`#/?q=安全带`）
- 证据等级筛选：A 有具体数字可查 / B 有研究支持 / C 经验与通行做法，首页与主题页都可用
- 主题页内二次过滤：在本主题内按关键词过滤条目
- 键盘：`/` 聚焦搜索，`Esc` 逐级返回，条目页用 `←` `→` 翻上一条/下一条

**其他**

- 纯静态，无构建步骤、无框架、无外部 CDN 依赖
- 深浅色主题，跟随系统并可手动切换
- 每条条目都有独立 URL（`#/i/13-07`），可直接分享到某一条
- 数据按主题拆分懒加载：首屏只拉 20KB 的主题清单 + 320KB 的搜索索引
